grep "^45\.77\.21\.90 " apache.log

3. Detect Path Traversal Attempts

Command:

grep -Ei '\.\./|%2e%2e|/etc/passwd' apache.log

Output:

45.77.21.90 - - [15/Nov/2026:10:20:11 +0500] "GET /../../etc/passwd HTTP/1.1" 403 450
103.25.10.44 - - [15/Nov/2026:10:25:33 +0500] "GET /index.php?page=../../etc/passwd HTTP/1.1" 500 600

Finding: Both IP addresses made suspicious path traversal requests.

Finding 4: HTTP Status Code Analysis

**Command:**
```bash
awk '$9 == 403 || $9 == 500' apache.log
```

**Analysis:**

- **45.77.21.90 – HTTP 403:** The request attempted to access `/../../etc/passwd`. Apache returned Forbidden, indicating that access was denied. This suggests the request was blocked, although the access log alone cannot prove whether any file access occurred internally.

- **103.25.10.44 – HTTP 500:** The request targeted `/index.php?page=../../etc/passwd`. The server returned an Internal Server Error while handling this request. This makes it important to investigate the PHP application logs to determine whether the request reached application code, caused an application failure, or resulted in any file access.

**SOC Assessment:** Both requests contain path traversal indicators. The 403 response indicates denied access, while the 500 response indicates a server-side failure. Neither response alone confirms successful reading or disclosure of `/etc/passwd`.

Finding: 403 means Forbidden, while 500 means Internal Server Error.

5. Count SSH Attempts by IP Address

Command:

grep -Ei "Failed password|Invalid user" ssh.log | grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' | sort | uniq -c | sort -nr

Output:

3 45.77.21.90
3 103.25.10.44

Finding: Each IP generated three failed SSH login attempts in this sample.

6. Count Path Traversal Requests by IP

Command:

grep -Ei '\.\./|%2e%2e|/etc/passwd' apache.log | awk '{print $1}' | sort | uniq -c | sort -nr

Output:

1 45.77.21.90
1 103.25.10.44

Finding: Each IP generated one matching path traversal request in this sample.
